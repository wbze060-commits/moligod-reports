# moligod 子弹行情自动化

国服《三角洲行动》子弹行情报告与条件交易提醒，运行在 GitHub Actions。

## 报告

- 日报：每天北京时间 22:30。
- 周报：每周日北京时间 22:30。
- 月报：每月 1 日北京时间 22:30。
- 覆盖 68 种子弹：3/4 级提供滚动行情统计，5 级提供实时行情。
- 报告保存为 HTML 和 PDF，数据快照保存在 data/。
- 统计比较近 7 天与此前 23 天，显示价格数据采集时间、有效样本数和 13% 税后基准。
- 公告仅接受明确标注 `CN` 且带 `df.qq.com` 文章链接的国服信息。国服自动公告源暂不可用；`data/cn_official_news.json` 可保存人工核验的官网公告。Steam 国际服和未标注区服的旧信息会被过滤，30 天后隐藏。

## 日抛与周抛买卖计划

日报提供次日的日抛条件计划，周报提供周抛条件计划。行情和阈值均为哈夫币，操作时间为北京时间。

| 内容 | 日抛 | 周抛 |
| --- | --- | --- |
| 数据 | 最近15天小时线，至少10个完整交易时段 | 最多30天完整日线，至少14天 |
| 买入 | 06:00–11:59，回到买入区再核价入场 | 当周进入买入区再核价入场 |
| 卖出 | 13:00–18:59到目标卖出，18点时段提醒复核退出 | 达目标可提前卖出，周日18点时段提醒复核退出 |
| 验证 | 较早数据训练，最后5天单独验证 | 每次此前14天训练，随后7天验证，验证窗口不重叠 |
| 筛选 | 验证至少3次模拟成交，到目标比例至少60%，模拟合计净空间为正 | 验证至少2次模拟成交，同样要求；近期持续下跌暂停买入 |

早盘和午后是使用者要求的操作窗口，不是模型已证明的必涨时段。没有通过筛选时直接提示观望，不强行推荐子弹。验证不包含真实成交量与挂单排队，不能视作实盘胜率。

每个候选显示：当前报价、买入区间、卖出目标、保本卖价、含滑点的保本价、失效线、有效期、模拟验证样本和结果。价格在计划有效期内固定，避免持有期间不断移动卖出目标。日抛计划过期后重建，周抛按自然周重建。

参数位于 `data/trade_config.json`。默认按13%卖出费率，并额外留2%卖价滑点；实际保证金及其他费用需另核对。例如100买入，至少挂115才覆盖13%费率，含滑点缓冲需118。行情跌破计划线不等于净损失只有5%，手续费和跳价会扩大实际损失。

小时盯价在抓取数据后运行 `python cloud_trade.py`，只对通过筛选的计划推送买入区、目标卖价、失效和到期提醒。同一计划、弹种、事件只提醒一次；推送失败不登记成功。延迟导致已过期的提醒只提示复核退出，不建议补买。

报价采集时间和最新小时线都需在3小时内；缺失或过期时暂停到价建议。3小时是容错上限，交易前必须核对游戏内即时挂单。GitHub Actions 定时运行可能延迟，不能保证及时抢购。计划不自动下单，也不推断你持有某种子弹；卖出前需核对个人买入成本。

行情来自第三方 moligod，不是腾讯官方报价。当前目标区服固定为 `CN`，交易前须确认第三方报价与国服实盘一致。公告与行情互相独立，当前不自动把公告转成涨跌预测。

## 本地验证

无新增依赖。PowerShell：

```powershell
$env:PROJECT_ROOT = (Get-Location).Path
python -m unittest discover -s tests -v
```

生成报告需已有 `data/catalog.json`、`data/history_latest.json`、`data/market_meta.json`。首次执行 `python cloud_fetch.py` 获取行情时会读取已有历史快照，修复接口 `r30` 为空时的日线缺失。

## 盯价提醒

- .357 Magnum FMJ：每 5 分钟检查；最新价或今日最高价达到 800 时提醒，冷却 6 小时。
- 重点子弹：每小时检查指定列表，较上一快照涨跌达到 5% 时提醒。
- 三级弹策略：每小时检查指定买卖线，状态进入买入/卖出区间时提醒。
