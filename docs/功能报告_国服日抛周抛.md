# 国服子弹日抛、周抛功能报告

此版本为待审核的源码候选，尚未合并到线上 `main`。适用国服《三角洲行动》，以哈夫币计价。

## 已实现

| 功能 | 结果 |
| --- | --- |
| 国服消息过滤 | 报告仅展示明确标注 `CN` 的有效消息；Steam 国际服及无区服信息的旧消息被排除 |
| 国服公告状态 | 停用 Steam 自动源；国服稳定自动源尚未接通，明确提示不可用；支持人工核验官网链接后导入 |
| 行情修复 | `r30` 为空时聚合小时线；去除 `r7/r15` 重复小时；复用仓库历史快照补齐滚动日线 |
| 日抛计划 | 早盘06:00–11:59条件入场、午后13:00–18:59目标退出；夜间日报提供次日计划 |
| 周抛计划 | 自然周条件入场、到目标可提前退出、周日18点时段复核清仓 |
| 买卖价格 | 买入区间、买入上限、卖价目标、13%费率保本价、含2%滑点缓冲的保本价、失效线 |
| 回测 | 按时间先后训练和验证；不使用未来点、不把同根K线低点买入高点卖出当成可实现成交 |
| 筛选与观望 | 日抛至少3次验证成交、周抛至少2次，且到目标比例至少60%、合计模拟净空间为正；不足就观望 |
| 行情过期保护 | 同时检查采集时间与最新小时线，超过3小时或缺失时间时暂停到价建议 |
| 微信内容 | 价格、操作窗口、有效期和验证结果进入摘要；小时盯价可发送到价、失效和到期提醒 |
| 去重与重试 | 同一计划、弹种、事件只记录成功推送；发送失败不登记成功 |

默认只给3/4级弹生成策略，5级仍展示实时行情。早盘、午后是使用者要求的操作窗口，不代表已证明这两个时段有稳定价差。

## 真实快照演示

仓库快照采集完成于 **2026-10-15 22:12 北京时间**，包含67款目录报价、68款历史记录。小时线末根为同日21:00，与北京时间最近完成小时相符；无时区标签的小时线按北京时间解释，此为当前数据口径。

将最新快照与仓库历史日线合并后运行，日抛、周抛都没有通过全部筛选的推荐。预览如实显示观望。观察候选的买卖线只是待验证的计划条件，不能作为当前买卖指令。

示例：日抛观察候选 `45-70 Govt RN`，买入区622–654、目标791；最近5个验证时段只有2次模拟入场、1次到目标，合计模拟净空间为负，因此未推荐买入。真实快照预览位于交付目录的 `preview/国服买卖计划预览.html`。

## 验证证据

- 29项单元与回归测试通过：覆盖区服过滤、官网域名、过期、小时聚合、历史回填、年份边界、手续费、先后顺序、留出期逆转、周验证窗口、计划冻结、去重、微信内容。
- 10份Python源码通过AST解析，4个workflow通过YAML解析。
- 使用真实仓库快照生成日报、周报HTML，两个进程均退出0；微信摘要提取成功。
- 固定输入对比：原版显示国际服测试消息、小时回退结果为空且无日抛/周抛计划；候选过滤该消息、聚合出有效日线并生成两类国服计划。
- 交付的 `VERIFICATION.txt` 保存命令、标准输出、标准错误、退出状态、文件哈希与回滚对照。

## 使用边界

1. moligod是第三方行情，未获得腾讯官方行情接口的区服证明，必须在国服游戏内核价。目标配置为 `CN` 不等于报价经过官方认证。
2. 国服自动公告抓取尚未接通，当前不会把消息面用于价格预测。官方入口为 https://df.qq.com/ 。
3. 策略筛选结果来自有限历史样本。验证使用当时训练出的价位，展示的下一期计划价位会用全部已知历史重新估算；验证结果不等于新目标的实盘胜率。
4. 报价不是成交；模拟不包含实际成交量、挂单排队、保证金和额外费用。13%费率可配置，需核对游戏内实际费用。
5. 含费率和滑点，报价跌5%退出的净损失可能接近19%，跳价还可能更大。失效线不保证最大亏损。
6. 尚无真实持仓、数量、买入均价记录，卖出提示是条件提醒，不推断你确实持有或一定盈利。
7. GitHub Actions 定时可能延迟。到价提醒和到期提醒均非实时保证，无法替代对分钟级抢购的持续监控。
8. 本轮未进行真实微信发送，也未重新运行联网抓取和PDF转换；本机访问moligod与国服官网正文遇到TLS/超时问题。行情验证使用已从仓库读取的真实快照。

## 主要文件

- `trade_strategy.py`：日抛、周抛模型、顺序验证、状态判断。
- `cloud_trade.py`：计划持久化、到价提醒、去重。
- `cn_news.py`、`cloud_news.py`、`report_data.py`：国服消息入口和行情整理。
- `cloud_fetch.py`、`cloud_report_all.py`、`cloud_push.py`：抓取、报告和微信摘要集成。
- `data/trade_config.json`、`data/cn_official_news.json`：策略参数和人工核验公告。
- `.github/workflows/`：保留既有时刻，小时盯价增加策略提醒；报告文件名统一北京时间。

## 合并后的验收

仓库拥有者确认后合并候选，再手动运行一次 `小时盯价` 和 `moligod 日报`，核对国服提示、数据时间、计划状态、HTML/PDF和微信摘要。没有合格信号时应显示观望，且不推送买入提醒。
