# 国服日抛、周抛机器人上线使用指南

2026-10-15 23:32（北京时间），PR #1 已合并到 `main`，合并提交 `3cc2f085c3458a081bfe96934745998cde169c5c`。

源码已上线。首次新版抓取、报告、微信发送仍需手动运行验收；GitHub Pages 发布状态与报告任务状态应分别查看。

## 一、先运行“小时盯价”

1. 用仓库拥有者的 GitHub 账号打开：[小时盯价](https://github.com/wbze060-commits/moligod-reports/actions/workflows/hourly-watch.yml)。
2. 在运行记录上方找到 **Run workflow** 按钮，点击展开。
3. 将 **Branch** 选为 **main**，再点击展开框内绿色的 **Run workflow**。
4. 刷新页面，找到刚出现的最新运行记录，点击进入。不要打开旧记录，也不要点旧记录的 **Re-run jobs**，旧记录可能继续使用旧代码。
5. 点击任务 **watch**，展开各步骤。需要看到下面步骤通过：
   - 抓取实时价。
   - 盯价 + 微信推送。
   - **国服日抛与周抛到价提醒**。
   - 回传快照。
6. 等整条记录变为绿色勾号，再运行后面的日报。

没有合格信号时，策略步骤可能输出 `TRADE_ALERTS pending=0 sent=0`，这是正常结果，不会强行给你发买入提醒。历史价格异动提醒仍可能单独发送。

如果页面没有 **Run workflow**：确认已登录拥有这个仓库权限的账号，确认打开的是上面的具体 workflow 页面，刷新后重试。需要的 `workflow_dispatch` 已在 `main` 配置好。

## 二、运行一次新版日报

1. 打开：[moligod 日报](https://github.com/wbze060-commits/moligod-reports/actions/workflows/daily-report.yml)。
2. 点击 **Run workflow → Branch: main → 绿色 Run workflow**。
3. 刷新并进入最新运行记录，点击任务 **report**。
4. 依次检查：抓取数据 → 检查国服公告 → 生成日报 → 安装 Chrome → 转 PDF → 提交报告 → 微信推送。
5. 全部完成后，在微信打开本次推送中的 **完整报告 HTML**；需要保存时打开 **PDF 版**。

公告步骤出现 `CN_NEWS_MANUAL_ONLY headlines=0` 表示当前没有人工核验的国服公告，属于正常情况，不影响价格模型。它不代表已接通腾讯国服自动公告接口。

小时盯价没有触发信号时可以不发微信；日报任务成功执行推送后才应收到日报消息。请分别判断，不要仅凭“没收到盯价消息”认定失败。

## 三、需要立即看周抛时，再运行一次周报

打开 [moligod 周报](https://github.com/wbze060-commits/moligod-reports/actions/workflows/weekly-report.yml)，同样选择 **Run workflow → main → Run workflow**。

首次验收按“小时盯价 → 等完成 → 日报 → 等完成 → 周报”顺序运行，便于定位问题。后续自动执行，无需每天手动点击。

## 四、收到计划后怎么操作

所有时段均为北京时间；报价单位为哈夫币。这里的时段是操作窗口，不是保证上涨的规律。

| 报告字段 | 你怎么使用 |
| --- | --- |
| 通过历史筛选 | 才进入考虑买入的候选；仍要核对游戏内实盘 |
| 仅观察／没有合格推荐 | 暂不按这份计划买入，等待新数据 |
| 买入区间、买入上限 | 在有效时段核对国服挂单，价格进入区间后再考虑限价买入；超过上限不追 |
| 卖出目标 | 确实持有该子弹时，结合个人买入成本和实际费用判断是否卖出 |
| 保本卖价 | 对照个人成本重新计算，不能把模型的计划成本当成自己的真实买入成本 |
| 失效线 | 跌破后取消未成交买单；已持有则复核退出，避免继续按旧逻辑补仓 |
| 有效期／清仓时段 | 到期重新评估，不自动延长持有期限 |
| 行情过期 | 等待刷新，同时直接核对游戏内即时挂单 |

### 日抛

- 夜间日报通常提供次日计划。
- 06:00–11:59 为买入窗口。只有价格、筛选状态和数据时效都满足时，才考虑入场。
- 13:00–18:59 为计划卖出窗口，达到目标可卖；18点时段提示复核退出。
- 下午收到延迟的买入消息时，查看有效期与最新状态；已经过了买入窗口，就取消这次买入安排。

### 周抛

- 在该自然周内，价格进入买入区后再考虑买入。
- 达到目标可以提前卖出。
- 最晚周日18点时段复核清仓，未成交的买单取消；周日夜间报告生成下一周计划。

系统尚未记录你的真实成交、持仓数量和买入均价。卖出提醒不是“已经替你买入”，也不能证明你现在卖出一定盈利。

## 七、遇到问题怎么看

| 情况 | 处理方法 |
| --- | --- |
| 运行记录是红叉 | 进入记录 → 点击 watch 或 report → 找第一条红色步骤。记录步骤名称和错误末尾几行反馈；不要公开密钥或整段推送响应 |
| 日报成功但微信没有消息 | 检查“微信推送”步骤是否成功，区分它与其他已成功的抓取/报告步骤 |
| 小时盯价成功但没有策略消息 | 先看是否 `pending=0`，无合格信号就不推送；同一计划同一事件已通知过也不会重复发送 |
| HTML/PDF链接暂时打不开 | 先确认报告已提交，然后到 [Actions](https://github.com/wbze060-commits/moligod-reports/actions) 查看对应的新 **pages build and deployment** 是否完成，再刷新链接 |
| 想看历史报告 | 从微信旧消息里的HTML/PDF链接打开，或在 [reports目录](https://github.com/wbze060-commits/moligod-reports/tree/main/reports) 查找日期文件 |
| 公告区没有消息 | 国服自动公告源尚未接通，目前不会拿 Steam 国际服公告替代；不影响纯行情策略计算 |

## 八、收益和数据限制

当前13%卖出费率与2%卖价滑点均为模型口径，实际费用需在游戏内核对；保证金及其他费用另计。报价跌5%退出不代表只亏5%，扣费和跳价会扩大损失。

行情来自第三方 moligod，目标区服配置为 `CN` 并不代表数据获得腾讯官方认证。每次买卖前都应核对国服实盘。

最近演示快照截至2026-10-15 22:12，没有通过全部筛选的日抛或周抛标的。这是该时点结果，后续以新报告为准；不要把预览中的观察价位当成当前买卖指令。

手动运行按钮操作可参阅 [GitHub官方说明](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manually-run-a-workflow)。
